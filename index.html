    Platforms and frameworks

    The learning platforms, frameworks, communities and other sources this catalogue refers to.

    Where the learning comes from

    Most of the learning in this catalogue comes from these platforms. Check each one for who can use it and any booking deadlines.

    • Digital and Data Hub: industry-led learning (opens in new tab)Free self-paced courses from technology providers. Open to anyone.
    • Get Tech Certified 2026 (opens in new tab)Free certifications and courses for public sector employees with a work email. Closes 31 December 2026.
    • Government Campus: Technology and Software (opens in new tab)Trainer-led courses for civil servants, booked through the Learning Frameworks portal. Book by 31 January 2027.
    • Government Campus: Government Digital and Data Profession (opens in new tab)Courses for the digital and data profession, grouped by level.
    • Civil Service Learning (opens in new tab)Learning for all civil servants. Not yet reviewed for this catalogue.
    • National Careers Service: Skills Bootcamps (opens in new tab)Digital bootcamps of up to 16 weeks for adults in England.
    • AI Skills Hub (opens in new tab)AI courses and programmes. Needs a free account.
    • Digital and Data Hub: Spotlight webinars (opens in new tab)Short introductory webinars, with past recordings.

    Frameworks and standards

    These describe the skills, levels and standards the catalogue is built around.

    • Government Digital and Data Profession Capability Framework (opens in new tab)The roles, levels and skills used for assessment and career progression. Each topic in this catalogue is mapped to one of its skills.
    • Service Manual (opens in new tab)Guidance on building government services, including the software engineering community guides.
    • The GDS Way (opens in new tab)Technology standards and good practice from the Government Digital Service.
    • GOV.UK Design System (opens in new tab)Styles, components and patterns for building accessible services.
    • NCSC secure development and deployment guidance (opens in new tab)Principles for developing and deploying software securely.
    • Web Content Accessibility Guidelines (WCAG) 2.2 (opens in new tab)The accessibility standard that services need to meet.

    Communities

    Places to learn from other engineers.

    • Cross Government Software Engineering Community (opens in new tab)Events, conferences and special interest groups for engineers across the public sector.
    • Community events (opens in new tab)Monthly lean coffees and GovDev conferences.
    • Special interest groups (opens in new tab)Including sustainable software, open source and Heads of Engineering.
    • Software developer learning pathways (opens in new tab)A community-written pathway of developer competencies at junior, mid and senior level.

    Practise with real APIs

    Public APIs you can use to practise calling, testing and integrating with services.

    • GOV.UK Content API (opens in new tab)No sign-up needed. A simple first API to practise with.
    • Companies House API (opens in new tab)Live company data with a free API key.
    • HMRC Developer Hub (opens in new tab)A sandbox with test users for practising OAuth 2.0 and API integration.

    How this catalogue was made

    Sources used to decide which topics to include.

    • Cross-government open source repository list (opens in new tab)Public code from over 200 public sector organisations, used to find the tools and practices teams use.
    • GOV.UK developer documentation (opens in new tab)How GOV.UK builds, tests and runs its services.
    • Software development life cycle (opens in new tab)The life cycle phases the stages are based on.
